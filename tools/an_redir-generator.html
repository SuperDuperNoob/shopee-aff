Shopee Affiliate Link Generator

No AppID / Secret needed — builds official an_redir link from your affiliate_id

Official method. This uses Shopee's documented https://<domain>/an_redir?origin_link=<ENCODED>&affiliate_id=<ID>&sub_id=<...> — same tracking as shp.ee via API, but generated locally. See without-appid-workarounds.md for research & alternatives (Involve Asia, dashboard, etc.).
Find it: Affiliate Portal → Custom Link → generate one link → copy affiliate_id= value. Never commit it to Git.

No server. All work happens in your browser. Your affiliate_id is saved to localStorage only on this device.
Need scale? Use the CLI: node tools/generate-anredir-link.js --affiliate-id ... --url ... --sub-id ...
Alternatives without any Shopee account: see Involve Asia / ACCESSTRADE route in the guide.

How to verify
  1. Paste one product URL + your affiliate_id → Generate.
  2. Open the result in an incognito window — you should land on the product.
  3. Wait 15–30 min → Affiliate dashboard → Analytics / Conversion Report → filter by sub_id → click should appear.
  4. For a second product, change only Sub_id to track channel performance.

If clicks don't appear, check that your affiliate_id is for the same market (VN vs SG etc.) as the product URL, and that the account is active.
